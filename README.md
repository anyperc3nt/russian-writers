# Русские писатели: время и связи

Онлайн-версия: https://anyperc3nt.github.io/russian-writers/

Откройте `index.html` двойным щелчком в современном браузере. Интернет и локальный сервер для работы страницы не нужны. Сохраните все файлы этой папки вместе.

По умолчанию страница показывает 22 имени из «списка с картинки Ани». Переключатель открывает расширенный список из 83 литераторов; для обеих выборок доступны поиск и выгрузка CSV. На временной шкале выделены XVIII век, XIX век, начало ХХ века, советский период и современность. Всего собрано 50 документированных связей. Цвет полосы показывает одну из шести широких литературных групп; такая классификация условна и не исключает принадлежности автора к нескольким направлениям. Дуги обозначают встречи, дружбу, переписку, сотрудничество и литературную полемику. Их ширина зависит от расстояния между строками: длинные связи уходят левее; соседние линии разводятся по отдельным дорожкам. Нажатие на имя приглушает остальные связи и облегчает выбор нужной дуги. Наведение на дугу открывает описание; нажатие показывает ссылку на источник. Выгрузка CSV работает в браузере, а полная таблица также лежит в файле `writers.csv`.

Данные хранятся в `data.js`. Чтобы добавить автора, внесите имя и годы жизни в `WRITERS` и включите его имя в одну из групп `WRITER_GROUPS`. Чтобы добавить связь, внесите запись в `RELATIONSHIPS` с двумя именами из списка, типом, кратким описанием и URL источника. Страница автоматически сортирует авторов по году рождения.

Источники для связей указаны в `data.js` и доступны из интерфейса. Общий список для сверки годов жизни: [List of Russian-language writers](https://en.wikipedia.org/wiki/List_of_Russian-language_writers). Для Екатерины II использован также [каталог НЭБ «Собеседник любителей российского слова»](https://kp.rusneb.ru/item/material/sobesednik-lyubiteley-rossiyskago-slova-ch-1).

Древнерусская литература пока не представлена: шкала начинается с 1700 года. Классификация ориентируется на обзорные материалы [«Золотой век русской литературы»](https://www.culture.ru/s/vopros/zolotoj-vek-russkoj-literatury/) и [«Гид по Серебряному веку»](https://www.culture.ru/s/gid-po-serebryanomu-veku/).

Составлено в октябре 2026 года. Это исследовательская выборка, а не полный список русскоязычных авторов и всех их контактов.
